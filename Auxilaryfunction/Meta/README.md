辅助多功能mod，纯辅助功能无任何作弊类
默认快捷键 alt+2
语言/Language:中文，English

<details>
<summary><b>📖 功能总览 · 界面说明 · 使用指南（点此展开）</b></summary>

> 纯辅助 mod，无作弊类功能。所有开关**默认关闭**，需要时在面板里手动勾选，配置会自动保存到
> `BepInEx/config/cn.blacksnipe.dsp.Auxilaryfunction.cfg`。

### 一、快速上手

| 操作 | 效果 |
| --- | --- |
| `Alt + 2` | 开 / 关主面板（默认快捷键，可在面板内改） |
| `Ctrl + F` | 开 / 关「蓝图设置」面板：直接在鼠标位置打开并切到该页签（默认快捷键） |
| 拖动标题栏 | 移动面板 |
| 拖动左 / 右 / 下边缘 | 缩放面板（最小 100×100） |
| `Ctrl` + 鼠标滚轮，或 `Ctrl + ↑ / ↓` | 调整面板字号（5–35，默认 16） |
| 面板内滚轮 | 滚动当前页签内容 |

- 面板贴合在游戏画面之上，打开时会同步一次位置与大小；关闭时清理拖动/缩放状态，不会出现"关掉后尺寸仍被改"的问题。
- 窗口尺寸（830×660）与位置、字号都会记住，下次启动沿用。
- 快捷键可在面板内重新设置：点「改变窗口快捷键」/「改变蓝图设置快捷键」后按下组合键，再点「点击确认」。
  支持修饰键（左 Shift / 左 Ctrl / 左 Alt）+ 主键（数字 0–9 优先，其次字母 A–Z，最后 F1–F10），也支持单键；两个快捷键互斥设置。

### 二、主面板界面

标题栏显示 `辅助面板(3.1.1)ps:ctrl+↑↓`，下方是一排 7 个页签按钮（当前页签高亮），内容区可滚动：

**自动菜单** · **渲染屏蔽** · **便捷小功能** · **文字科技树** · **戴森球面板** · **战斗** · **蓝图设置**

<summary><b>① 自动菜单</b> —— 物流站 / 采矿批量配置、机甲自动化</summary>

#### 物流站与采矿

- **自动配置新运输站**（默认关）：新建物流站 / 大型采矿机时，按下方参数自动完成设置，省去逐个点选。
- **配置参数**（默认开）：11 条参数各带一个「启用」勾选，只有勾选的项才会被自动配置或批量配置：

| 参数 | 范围 | 默认 |
| --- | --- | --- |
| 填充飞机数量 | 0–100 | 10 |
| 填充飞船数量 | 0–10 | 5 |
| 最大充电功率 | 30–300 MW | 30（非星际站上限 60 MW） |
| 运输机最远路程 | 20–180° | 180° |
| 运输船最远路程 | 1–61 ly | 61（显示为 ∞） |
| 曲速启用路程 | 0.5–60 AU | 12 AU |
| 运输机起送量 | 0.01–1（显示 1%–100%） | 10% |
| 运输船起送量 | 0.01–1 | 100% |
| 翘曲填充数量 | 0–50 | 0 |
| 大型采矿机采矿速率 | 1.0×–3.0× | 1.0× |
| 填充配送机数量 | 0–10 | 10 |

- **填充当前星球飞机飞船、翘曲器**：扫描当前星球所有物流站，把飞机 / 飞船 / 翘曲器补齐到上面设定的数量（物品从背包扣除）。本地站飞机上限 50，星际站上限 100，飞船只补星际站。
- **批量配置当前星球物流站**：把上面启用的参数一次性套用到当前星球全部物流站（含星际站专属的翘曲、飞船参数）。
- **批量配置当前星球大型采矿机采矿速率**：按设定倍率统一设置大型采矿机（含矿脉采集器）。
- **铺满轨道采集器**：仅气态星球可用。要求该星球**没有**已建或未完成的建筑，且背包里至少有 40 个轨道采集器；确认后按环带布局一次性铺设 40 个（并扣除背包物品）。

#### 科技队列

- **自动添加科技队列**：勾选后，后台每秒检查，只要研究队列为空就把指定科技入队，一直研究到设定等级。
  - **科技等级上限**：默认 500，可输入 0–10000；点科技按钮可在列表里选择目标科技（只列出未满级且等级上限 >10 的科技）。
  - **沙盒模式秒解锁科技**：仅在开启沙盒工具时出现，勾选后直接解锁而不入队。

#### 自动填充

- **自动填充人造恒星**：选择燃料（1803 / 1804 两种），数量 1–100（默认 4）；开关打开后新建人造恒星会自动带燃料，也可以用「填充当前星球人造恒星」把当前星球全部人造恒星补满。
- **自动填充配送运输机**：数量 0–10（默认 10）；新建配送器自动补配送机，也可用「填充当前星球配送机」批量补齐。

#### 垃圾处理（两项互斥）

- **30s 间隔自动吸收垃圾**：每约 30 秒把地上的垃圾标记为即将回收；可选「只回收建筑」——勾选时只有可建造物品会被回收，其余直接清除。
- **30s 间隔自动清除垃圾**：每约 30 秒直接清空全部垃圾。

#### 机甲自动化

- **自动飞向未完成建筑**：仅飞行状态可用。屏幕左侧出现「开始寻找未完成建筑」按钮，开启后机甲自动飞向最近的未完成建筑（优先有材料的），配合建筑机自动建造；可调「时间间隔」1–10 秒。
  - 该模式下机甲碰撞体会被关闭，避免卡在建筑里；「开始自动补充材料」（非气态星）会从物流站、储物箱、储液罐中取材料补满背包。
- **自动飞向地面黑雾基地**：仅飞行状态可用。出现「开始飞向黑雾基地」按钮，自动飞向最近的地面黑雾基地；可开「开始自动填埋」在基地被摧毁后自动填平残骸。
- **自动导航**（开启后的子项）：
  - **自动加速**：主动加力加速，飞得更快。
  - **自动导航使用曲速**：距离超过阈值且驱动器等级 ≥3、能量与翘曲器充足时自动启动曲速。
  - **自动曲速最低距离**：0–15 光年。
  - **自动曲速最低能量**：0–95%（5% 步进）。
  - 使用方式：先在地图 / 列表上建立目标标记（星球、恒星、火种、通讯器、黑雾巢穴均可），开启自动导航后会自动起飞、加速、按距离逐级减速、必要时曲速，抵达后自动结束。飞行中屏幕左侧有「暂停导航 / 继续导航 / 取消方向指示」按钮。
  - 目标星球在当前星球背面时会先拉起绕行，避免直线撞地；目标星球尚未加载时会等待加载再曲速。

- 关闭玩家走路 / 飞行声音。

<summary><b>③ 便捷小功能</b> —— 蓝图优化、物流站信息、时间流速、夜灯、垃圾桶</summary>

**蓝图功能优化**

- **蓝图全选**（`Ctrl + A`）：蓝图复制模式下全选当前星球所有建筑。
- **蓝图删除**（`Ctrl + X`）：蓝图复制模式下删除选中建筑并回收物资（物流站内的物品会返还背包）。
- **记录上次蓝图路径**：蓝图浏览器下次打开时自动回到上次的目录。
- 在蓝图粘贴模式下按 `Ctrl + Z` 可直接回到蓝图复制模式（相当于"撤销后重选"）。

**物流站功能优化**

- **物流站信息显示**：在 3D 场景里，物流站上方直接悬浮显示内部物品与状态，无需逐个点开。
  - 显示内容：物品图标与数量（最多 5 格，轨道采集器 2 格）、本地 / 星际的供应（蓝）/ 需求（橙）/ 仓储（灰）方向、物流站名称、飞机 / 飞船 / 翘曲器数量（总数 + 空闲数）。
  - **详细模式**：本地与星际各显示一个方向图标。
  - **简易模式**：只显示物品与数量，星际站 / 轨道采集器合并为一个星际方向图标。
  - **建筑 / 蓝图模式下也显示**（默认关）：开启后建筑模式（含蓝图复制 / 粘贴）也能看到提示。
  - 被星球遮挡、在视线背面、没有物品的物流站不会显示；提示框会随距离缩放。
- **物流站物品设置复制粘贴**：用游戏自带的建筑参数复制 / 粘贴（`Ctrl+C` / `Ctrl+V`）时，连带复制物流站的 5 格物品配置（物品、上限、本地逻辑、星际逻辑、排序），粘贴时自动返还目标站原有的物品。蓝图模式下不生效。
- **改变窗口快捷键**：见"快速上手"。

**时间流速**

- **启动时间流速修改**：改变逻辑帧步长从而加速 / 减速游戏。
- **流速倍率**：输入框或滑条设置，范围 **0.01–10**（保留两位小数，默认 1.00）。
- **加速减速(shift,'+''-')**：勾选后，按住 `Shift` + 小键盘 `+` / `-` 每次微调 0.01，范围同样是 0.01–10。
- **停止工厂**：暂停工厂生产与建筑逻辑帧，但保留玩家操作、物理与音频，方便慢慢摆布局；也可用 `Ctrl + 空格` 快速开关（需先勾选「ctrl+空格快速开关」）。

**其它**

- **修改自动保存时长**：勾选后可输入自动保存间隔（分钟，1–10000），立即写入游戏设置生效。
- **保持传送带高度(shift)**：从已有的传送带、集装机、四项分流器拉出传送带时，按住 `Shift` 可保持原高度。
- **科技面板选中不缩放**：选中科技节点时不让科技树面板跳动 / 缩放。
- **背包垃圾桶**：开启后背包界面右上角出现垃圾桶按钮，点击打开一个 30 格垃圾桶窗口（可排序），关闭垃圾桶时自动清空内部物品。
- **夜灯**：把本地恒星的光"挂"到机甲上方并让太阳光方向跟随角色，使行星表面始终被照亮，夜间施工不再黑屏；在蓝图（白色）模式下自动关闭，避免过亮。

<summary><b>④ 文字科技树</b> —— 用列表代替图形科技树，一键排队与买断</summary>

界面分三段：**准备研究** / **科技** / **升级**。

- **准备研究**：已排入队列的科技列表，点击某项即从研究队列与列表中移除。
- **科技 / 升级**：当前"可以研究"的科技列表（升级科技单独归到「升级」段），点击即加入「准备研究」。
- 每个科技下方显示它需要的材料图标与解锁的配方图标，右下角是**买断**按钮（消耗元数据直接买断；沙盒模式下直接解锁科技）。
- **限制材料**：勾选后只列出所需材料都已解锁的科技，避免列出当前造不出来的。
- **自动顺序添加**（临时开关，**不写入配置**，每次进游戏默认关闭）：开启后后台每秒把当前可研究的科技自动加入「准备研究」并依次入队，排序规则为：
  1. 无限 / 多级升级科技（等级上限 ≥20）垫底，避免堵住队列；
  2. 需要矩阵档次低的优先；
  3. 档次相同时，需要矩阵种类少的优先；
  4. 再按"科技优先于升级"；
  5. 最后按矩阵消耗总量，少的优先。
- 只有**当前可研究**（前置全部解锁）、**尚未研究完**且**等级上限 ≤ 50** 的科技会出现在列表里并被自动添加；隐藏 / 废弃科技不显示。
- 游戏研究队列只有 7 格，入队由后台每秒按列表顺序补位，面板关闭时同样生效。

</details>

<summary><b>⑤ 戴森球面板</b> —— 蓝图导入 / 层级管理 / 自动画壳</summary>

**左侧：蓝图列表**

- **打开戴森球蓝图文件夹**：直接打开蓝图目录（`我的文档\Dyson Sphere Program\DysonBluePrint\`，子目录也会被扫描）。
- **刷新文件**：重新读取目录下的 `*.txt` 蓝图（文件带 `DYBP:` 头与签名校验，类型不匹配或损坏的文件会被忽略）。
- 按类型分组勾选：**单层壳** / **多层壳** / **戴森云** / **戴森球(包括壳、云)**，点选其中一个蓝图，右侧操作针对它生效。

**右侧：操作**

- **复制选中文件代码**：把蓝图内容复制到剪贴板，10 秒后自动清空剪贴板。
- **清除剪贴板**：立即清空。
- **应用蓝图**：把选中蓝图应用到当前选中的戴森球上（单层壳需要再点层级按钮指定层）。
- **自动生成最大半径戴森壳**：从戴森球最大轨道半径向下寻找可用轨道，自动添加层级，最多 10 层。
- **删除全部空壳**：清除所有没有节点的空壳层。
- **可用戴森壳层级**：2×5 共 10 个按钮，显示可用层号；点一下就把选中的单层壳蓝图导入该层。
- **不可用戴森壳层级**：勾选「勾选即可点击删除」后点击层号即可删除该层；若该层已有节点会二次确认，确认后清空结构再删除。

> 提示：面板操作的是游戏戴森球编辑器里**当前选中**的戴森球，不再跟着玩家所在星系走。

</details>

<summary><b>⑥ 战斗</b> —— 黑雾巢穴导航、火种与通讯器列表</summary>

- **黑雾巢穴自动导航**：开关 + **跟随距离** 10–240（约 1000 m – 0.60 AU，默认 1.00 AU）。开启后自动飞向黑雾巢穴并保持该距离跟随。
- **火种列表**：列出全部有效火种（黑雾派出的侵袭舰队），显示 **出发星系 / 目标星系 / 与玩家距离 / 离目标星系距离**，每行一个「导航」按钮，点击即设置为导航目标（需已开启自动导航，否则弹窗提示"未启用自动导航"）；距离会自动换算成 m / AU / 光年。
- **通讯器列表**：列出全部宇宙通讯器及与玩家的距离，同样支持一键导航。

<details>
<summary><b>⑦ 蓝图设置</b> —— 框选批量改配方 / 参数（默认 Ctrl+F）</summary>

- **改变蓝图设置快捷键**：默认 `Ctrl + F`，按 `Ctrl + F` 会在鼠标位置打开面板并直接切到本页签。
- 需要在**蓝图模式**下使用（即蓝图复制工具已激活且有蓝图数据），否则页签只显示「进入蓝图模式可使用」。
- **全选当前星球建筑**：把当前星球所有建筑加入蓝图选择。
- **删除选中建筑**：二次确认后删除选中建筑并回收材料；物流站内的物品会先返还背包再清空。
- **可修改建筑**：以图标形式列出蓝图中可批量修改的建筑，可多选，但**只能同类型一起改**（例如熔炉和制造台不能混选）。支持的类型与可用操作：

| 建筑类型 | 可批量设置 |
| --- | --- |
| 熔炉 / 组装机 / 原油精炼站 / 化工厂 / 微型粒子对撞机 | 一键套用配方图标（网格列表）、设为「无」配方清空；**额外产出 / 生产加速**切换；**开启警报 / 关闭警报** |
| 矩阵研究站 | 一键设置研究矩阵（6 种矩阵 + 无）、**科研模式**、额外产出 / 生产加速 |
| 炮塔（6 种） | **分组** 1–5 或取消分组；**参数配置**：地面 / 低空 / 高空 / 太空 四层各自设为 OFF / 低优先 / 均衡 / 高优先 |
| 行星物流站 | 批量**设置名称**；4 格物品配置（启用、物品、上限、本地逻辑）+「设置物流站物品」；「重置物流站参数」；「设置物流站参数」（运输机最远路程、最大充电功率、起送量） |
| 星际物流站 | 批量设置名称；5 格物品配置（本地 + 星际逻辑）、上限、「设置物流站物品」；**分组**（读取当前站 / 全选 / 反选 / 清空，按游戏实际分组数量显示）与**行为设置**（忽略配队 / 优先配队 / 只看配队 / 专属配队）→「应用到选中物流站」；「设置物流站参数」（含曲速启用路程、运输船最远路程） |
| 射线接收站 | **直接发电** / **光子生成** 一键切换 |
| 能量枢纽 | **放电 / 待机 / 充电** |
